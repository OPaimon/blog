这是一篇使用`mdx`编写使用astro渲染的文章。

- 支持 Markdown
- 通过 `src/content/config.ts` 定义 schema

# Markdown 语法
你可以使用标准的 Markdown 语法来编写内容。例如：

```md
# 标题
这是一个段落。
- 列表项 1
- 列表项 2

_倾斜_

__加粗__
```

上述会渲染为
# 标题
这是一个段落。
- 列表项 1
- 列表项 2

_倾斜_

__加粗__
